# Лабораторная работа №3

Каркас проекта взят из [teach-kirshdv/js-tasks](https://github.com/teach-kirshdv/js-tasks)

Выполненное задание: `lab3/src/core.js`

Тесты: `lab3/src/core.spec.js`

Запуск тестов:

```
cd lab3
npm install
npm test
```

Реализовано:
- `isInteger` - проверка на целое число через побитовое ИЛИ
- `even` - массив чётных чисел от 2 до 20
- `sumTo` - сумма чисел до n циклом
- `recSumTo` - сумма чисел до n рекурсией
- `factorial` - факториал
- `isBinary` - проверка, является ли число степенью двойки
- `fibonacci` - n-е число Фибоначчи
- `getOperationFn` - функция, которая запоминает значение и применяет к нему операцию
- `sequence` - генератор арифметической последовательности
- `deepEqual` - глубокое сравнение объектов рекурсией

# Лабораторная работа №4

Реализовано:
- Flexbox-вёрстка элементов интерфейса
- Grid-вёрстка главной страницы
- Все цвета вынесены в CSS-переменные
- CSS-анимация вращения обложки трека
- Страница загрузки трека с формой, содержащей различные типы полей
- JavaScript-класс `Track` с конструктором и методом форматированного вывода данных в консоль
- Создание объекта `Track` при отправке формы
- Использована методология БЭМ для именования CSS-классов

Основные файлы:
- `lab4/index.html` - главная страница с Grid-вёрсткой

- `lab4/artist.html` - страница артиста
- `lab4/upload.html` - страница загрузки трека
- `lab4/css/style.css` - стили сайта
- `lab4/js/formUploader.js` - обработка формы и класс `Track`
